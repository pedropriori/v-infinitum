02Passo a Passo

Cinco passos até o ar

Você precisa do Claude Code instalado — baixe em claude.ai/download. Funciona em Windows, Mac e Linux.

  1. Crie a pasta do projeto

    Um nome qualquer serve. É onde o seu player vai viver.

    mkdir meu-player
cd meu-player

  2. Abra o Claude Code

    No terminal, dentro da pasta:

    claude

  3. Cole o prompt

    O prompt completo está na seção 03 — O Prompt, logo abaixo. Cole e aperte Enter — se o Claude perguntar algo, confirme; se pedir pra instalar algo, aceite.

  4. Teste localmente

    Depois que o Claude terminar:

    npx http-server -p 3000

    Abra localhost:3000 — seu player já está rodando.

  5. Publique de graça

    Pra gerar links de embed reais:

    npx vercel --prod

    Login com GitHub ou e-mail, siga as instruções. No ar em menos de um minuto.

03O Prompt

Cole isso no Claude Code

Este prompt já nasceu de uma implementação real — inclui as decisões de arquitetura que evitam retrabalho (arquivos compartilhados, contrato de parâmetros, o truque do progresso inteligente). Troque os tokens de cor pela identidade da sua marca, ou use os valores padrão da Infinitum. 

Crie um player de VSL (Video Sales Letter) completo com identidade visual própria, em HTML + CSS + JS puro — sem framework, sem build step. Estrutura de arquivos:

1. theme.css — tokens de marca compartilhados (cor de fundo, cor de destaque, tipografia) usados pelas duas páginas abaixo. Evita duplicar a paleta em dois lugares.

2. storage.js — schema e funções de CRUD sobre localStorage para os vídeos (create/get/update/trash/restore/delete) e para salvar a posição de "continuar assistindo". Compartilhado pelas duas páginas — evita duplicar a lógica de dados e o risco de um typo de chave corromper o progresso salvo.

3. index.html — Dashboard de gerenciamento:
   - Header com logo + wordmark da marca, avatar
   - Sidebar: Meus Vídeos, Segurança, Configurações
   - Lista de vídeos: tabela com thumbnail, nome, data, plays, ações (editar, embed, excluir) — com abas Biblioteca / Top vídeos / Lixeira
   - Upload: modal com drag & drop de arquivo + campo de URL (aceita blob URL e URL direta)
   - Editor do vídeo: painel de configuração à esquerda + preview ao vivo em iframe à direita (toggle Desktop/Mobile)
     * Estilo: cor principal, background, cantos arredondados, toggles de controles (play grande/pequeno, desativar pause, barra de progresso, tempo, voltar/avançar 10s, volume, fullscreen, velocidade)
     * Progresso Inteligente: toggle, cor da barra, altura — a barra deve visualmente completar um pouco antes do vídeo realmente terminar, criando a sensação de que falta pouco
     * Smart Autoplay: toggle, texto do overlay, trecho inicial
     * Botões de Ação (CTA): toggle, texto, link de checkout, tempo pra aparecer, cor, subtexto
     * Continuar Assistindo: toggle, mensagem, botões continuar/reiniciar — só deve aparecer se o espectador já assistiu mais que alguns segundos, não a cada recarregamento trivial
     * Pixels: toggle, ID, percentuais de disparo (dispara um evento customizado a cada percentual, sem dependência externa)
     * Opções de Reprodução: smart pause, recomeçar, velocidade, fullscreen (desktop/mobile)
   - Modal de Embed: toggle Vídeo Responsivo, abas Recomendado / JavaScript / iFrame, código gerado, link direto, preview ao vivo, botão copiar

4. player.html — Player embedável:
   - Autoplay mutado (clique desmuta), sem controles nativos do navegador
   - Barra de progresso custom, seekable, com o efeito de "progresso inteligente" acima
   - Botão de CTA que aparece no tempo configurado
   - Texto "toque pra ativar o som" que some sozinho depois de alguns segundos
   - Continuar assistindo via localStorage
   - Disparo de pixels por percentual assistido
   - Recebe TUDO via query params na URL (vídeo, poster, cores, textos, tempos) — assim o dashboard só monta uma URL, sem gerar HTML dinâmico
   - Atalhos de teclado: espaço (play/pause), setas (± 10s)

Identidade visual (troque pelos tokens da sua marca, ou use estes padrões da Infinitum):
- Fundo #0A0A0A · Destaque/ação #D4AF37 · Acentos #5C2A7E e #9B1C2C · Texto #F8F6F0
- Tipografia Inter, com tracking largo no wordmark em caixa alta

Sem controle nativo de download nem velocidade exposta ao espectador. O dashboard gera o embed apontando pro player.html com os parâmetros da configuração salva daquele vídeo. Tudo funcionando junto, tudo em localStorage, zero backend.
04Como Usar

Do upload ao embed

Subir um vídeo

  1. Abra o dashboard (localhost:3000 ou seu link Vercel)
  2. Clique em Upload
  3. Arraste o MP4 ou cole a URL de um CDN
  4. Dê um nome e clique Salvar

Configurar o player

  1. Clique no vídeo na lista pra abrir o editor
  2. Ajuste cada seção na sidebar esquerda
  3. Ative o Botão de Ação, cole o link do seu checkout, defina em quantos segundos ele aparece
  4. Mude a cor da Progresso Inteligente pra combinar com sua página
  5. O preview ao lado mostra o resultado em tempo real

Embed na sua página

  1. Clique no ícone de Embed
  2. Copie o código
  3. Cole na sua página de vendas — HTML, WordPress, qualquer lugar
  4. Pronto. Seu vídeo rodando com player premium, seu.

Onde hospedar os vídeos

O player aceita qualquer URL de vídeo MP4. Opções mais econômicas:

Bunny CDN — ~R$0,05/GB Cloudflare R2 — 10GB grátis, egress zero Google Drive — bom pra testes Dropbox — troque dl=0 por dl=1
